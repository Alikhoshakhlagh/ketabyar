# کتاب‌یار
**سامانه‌ی هوشمند ثبت، تحلیل و اشتراک‌گذاری تجربه‌ی مطالعه‌ی کتاب**

پیاده‌سازی با Python و Django، پایگاه داده‌ی PostgreSQL، و رابط کاربری فقط با HTML و CSS (بدون حتی یک خط جاوااسکریپت). فرانت‌اند داخل خود جنگو با سیستم قالب (Template) ساخته شده است.

---

## ۱. اجرای سریع (با داده‌ی نمونه)

```bash
cd ketabyar
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```
سپس در مرورگر: `http://127.0.0.1:8000`

### حساب‌های نمونه (ساخته‌شده با `seed_demo`)
| نقش | نام کاربری | رمز عبور |
|---|---|---|
| مدیر کل | `admin` | `admin1234` |
| کاربر عضو (پرفعالیت) | `sara` | `ketab1234` |
| کاربر عضو دیگر | `ali`, `maryam`, `reza`, `neda`, `hamed`, `zahra`, `kian` | `ketab1234` |

`kian` پروفایل خصوصی دارد تا تفاوت عمومی/خصوصی دیده شود.
برای پاک کردن و ساختن دوباره‌ی داده‌ها: `python manage.py seed_demo --reset`

## ۲. اتصال به PostgreSQL

فایل `.env` کنار `manage.py` تعیین می‌کند به کدام دیتابیس وصل شویم. الان روی `DB_ENGINE=sqlite` است تا پروژه بدون تنظیم اجرا شود. برای PostgreSQL:

۱. در `setup_db.sql` رمز `change-me` را عوض کنید، بعد اجرا کنید (رمز کاربر postgres پرسیده می‌شود):
```bash
psql -U postgres -h localhost -p 5433 -f setup_db.sql
```
۲. محتوای `.env.example` را در `.env` کپی کنید و `DB_PASSWORD` را همان رمز بگذارید.
۳. جدول‌ها و داده‌ی نمونه:
```bash
python manage.py migrate
python manage.py seed_demo
```

## ۳. سطوح دسترسی

| سطح | چه کسی | چه کارهایی |
|---|---|---|
| **مهمان** | کاربر واردنشده | مرور و جستجوی کتاب‌ها، دیدن نقدها، نقل‌قول‌های عمومی، پروفایل‌های عمومی |
| **کاربر عضو** | هر کاربر ثبت‌نام‌کرده | قفسه‌ی شخصی، امتیاز، نقد، علاقه‌مندی، نقل‌قول/هایلایت، ثبت جلسه‌ی مطالعه، تحلیل روند، پروفایل عمومی |
| **مدیر** | کاربری با `is_staff` | پنل مدیریت: ثبت/ویرایش/حذف کتاب، نویسنده و دسته؛ نظارت بر کاربران و لاگ فعالیت؛ مدیریت نقدها؛ گزارش آماری کلی و جزئی + خروجی اکسل |

کنترل دسترسی در کد: `@login_required` برای عضو، `staff_required` و `StaffRequiredMixin` در `panel/views.py` برای مدیر.

### بخش «هوشمند»
- **پیشنهاد کتاب** (`reading/recommend.py`): ترکیب سه چیز — علاقه‌ی کاربر به هر دسته و نویسنده (از روی علاقه‌مندی‌ها، امتیازها و قفسه)، «کاربرانی با سلیقه‌ی مشابه چه کتابی را پسندیده‌اند»، و امتیاز وزنی کتاب. کنار هر پیشنهاد، دلیلش نوشته می‌شود.
- **امتیاز وزنی (بیزی)** در `catalog/models.py`: کتابی با یک رأی ۵ از کتابی با صد رأی ۴.۸ جلو نمی‌زند.
- **به‌روزرسانی خودکار قفسه**: با ثبت جلسه، کتاب «در حال مطالعه» می‌شود، صفحه‌ی فعلی جلو می‌رود و با رسیدن به صفحه‌ی آخر «مطالعه‌شده» می‌شود.
- **پیش‌بینی زمان تمام شدن کتاب** بر اساس سرعت ۳۰ روز اخیر.
- **بینش‌های متنی** در صفحه‌ی تحلیل: مقایسه با بازه‌ی قبل، پرمطالعه‌ترین روز هفته، سرعت مطالعه، نظم مطالعه.
- **رکورد روزهای پیاپی**، **تقویم حرارتی** ۱۷ هفته، **هدف سالانه** (بر اساس سال شمسی).

### تاریخ شمسی
همه‌ی تاریخ‌ها شمسی نمایش داده می‌شوند و فرم‌ها تاریخ شمسی می‌گیرند (مثل `۱۴۰۵/۰۷/۲۸`). تبدیل در `core/jalali.py` بدون کتابخانه‌ی جانبی نوشته شده و در دیتابیس تاریخ میلادی ذخیره می‌شود.

## ۵. ساختار پروژه

```
ketabyar/
├── config/          تنظیمات و آدرس‌های اصلی پروژه
├── core/            صفحه‌ی اصلی/پیشخوان، تبدیل تاریخ شمسی، فیلترهای قالب (templatetags/ketab.py)
├── accounts/        ثبت‌نام، ورود، پروفایل و پروفایل عمومی
├── catalog/         کتاب، نویسنده، دسته‌بندی؛ جستجو و فیلتر
├── reading/         قفسه، امتیاز، نقد، علاقه‌مندی، نقل‌قول، جلسه، لاگ فعالیت، آمار و پیشنهاد
│   ├── services.py      منطق اصلی (هر عمل در لاگ فعالیت ثبت می‌شود)
│   ├── stats.py         محاسبات تحلیلی (برای کاربر و مدیر مشترک)
│   ├── recommend.py     موتور پیشنهاد
│   └── management/commands/seed_demo.py   داده‌ی نمونه
├── panel/           پنل مدیریت سفارشی
├── templates/       قالب‌های HTML (پوشه‌ی partials تکه‌های مشترک است)
└── static/          css/main.css و فونت وزیرمتن
```

### الگوی کار جنگو (MVT) در یک نگاه
مرورگر آدرسی را باز می‌کند ← `urls.py` مشخص می‌کند کدام تابع در `views.py` اجرا شود ← ویو از `models.py` داده می‌خواند/می‌نویسد ← داده را به یک قالب در `templates/` می‌دهد ← HTML نهایی برای مرورگر فرستاده می‌شود.

## ۶. مدل داده (جدول‌ها)

| جدول | توضیح | ارتباط‌ها |
|---|---|---|
| `User` (جنگو) + `Profile` | کاربر، هدف سالانه/روزانه، عمومی/خصوصی | Profile یک‌به‌یک با User |
| `Category` | دسته‌بندی با رنگ | — |
| `Author` | نویسنده | — |
| `Book` | کتاب | چند‌به‌یک با Author (حذف نویسنده‌ی دارای کتاب ممنوع) و Category |
| `ShelfEntry` | وضعیت کتاب در قفسه‌ی کاربر + صفحه‌ی فعلی + تاریخ شروع/پایان | User × Book (یکتا) |
| `Rating` | امتیاز ۱ تا ۵ (با CheckConstraint) | User × Book (یکتا) |
| `Review` / `ReviewLike` | نقد و «مفید بود» | User × Book (یکتا) |
| `Favorite` | علاقه‌مندی | User × Book (یکتا) |
| `Quote` | نقل‌قول یا هایلایت + صفحه + یادداشت + عمومی/خصوصی | User، Book |
| `ReadingSession` | جلسه‌ی مطالعه: تاریخ، دقیقه، از صفحه تا صفحه | User، Book |
| `Activity` | لاگ فعالیت برای نظارت مدیر | User، Book |
